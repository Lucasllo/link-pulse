## Phase Goal

> Goal da ROADMAP (literal; ainda não está no formato de user story): Um cliente cria links curtos (gerados ou com alias) e é redirecionado para a URL original a partir do Postgres, num repositório que builda igual no Windows e no Linux, com CI verde desde o início.

Este plano entrega o caminho do avaliador para rodar a API localmente com dados de demonstração.

Escopo (revisão do plano): a Swagger UI (OpenAPI) e o README saíram deste plano para a `01-07-PLAN.md` (onda 5), separando a documentação do runtime local (compose, profiles e seed). Este plano ficou com 1 task e 7 arquivos.

<objective>
Permitir que o avaliador rode a API localmente (`make run` = Postgres 18 via `compose.dev.yaml` + profile dev com o seed `demo-link`) e provar por IT que os contexts dev/prod do Liquibase separam o seed.

Purpose: DATA-01 (contexts dev/prod) e a parte de runtime do CONT-03 (alvos `db-up`/`db-down` portáveis e comando equivalente sem make). A documentação (README e Swagger UI) é da 01-07.
Output: `compose.dev.yaml`, `application-dev.yml`, `application-prod.yml`, seed `002-seed-dev.yaml`, alvos `db-up`/`db-down` e `LiquibaseContextsIT`.
</objective>
