## Phase Goal

> Goal da ROADMAP (literal; ainda não está no formato de user story): Um cliente cria links curtos (gerados ou com alias) e é redirecionado para a URL original a partir do Postgres, num repositório que builda igual no Windows e no Linux, com CI verde desde o início.

Este plano entrega o "é redirecionado para a URL original a partir do Postgres", com o schema vindo do Liquibase.

<objective>
Fazer `GET /{code}` redirecionar (302, sem cache no navegador) para a URL de um link gravado no PostgreSQL 18, com schema criado só pelo Liquibase e Hibernate em `validate`. Código inexistente → 404 e link expirado → 410, sempre em Problem Details. Também cria a infraestrutura de ITs com Testcontainers que os planos seguintes reutilizam.

Purpose: REDIR-01, REDIR-02 e DATA-01 (schema e contexts; o seed dev e o IT de contexts são da 01-05).
Output: changelogs, entidade, repository, service de resolução, `RedirectController`, `LinkProblems`, `ApplicationConfig` (Clock) e a base de ITs (`TestcontainersConfiguration`, `AbstractIT`, `RedirectIT`).
</objective>
