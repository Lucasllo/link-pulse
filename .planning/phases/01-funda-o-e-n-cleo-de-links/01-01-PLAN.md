## Phase Goal

> Goal da ROADMAP (literal; ainda não está no formato de user story — ver nota no retorno do planner): Um cliente cria links curtos (gerados ou com alias) e é redirecionado para a URL original a partir do Postgres, num repositório que builda igual no Windows e no Linux, com CI verde desde o início.

Este plano entrega a parte "repositório que builda igual no Windows e no Linux, com CI verde desde o início". É a fundação do Walking Skeleton descrito em `SKELETON.md`.

<objective>
Criar o repositório Maven em `app/` que builda de forma reproduzível no Git Bash do Windows (caminho com espaço, `core.autocrlf=true`, sem Maven instalado) e no Linux, com Checkstyle e SpotBugs quebrando o build em violação e com o workflow de CI rodando `./mvnw -B -ntp verify` a cada push/PR.

Purpose: CONT-03, QUAL-03 e CI-01. Todo código das próximas fases nasce dentro destes gates.
Output: wrapper + pom + app mínima respondendo health; configs de Checkstyle/SpotBugs; `ci.yml`, `dependabot.yml` e `Makefile`.
</objective>
