## Phase Goal

> Goal da ROADMAP (literal; ainda não está no formato de user story): Redirects saem do cache Valkey e continuam funcionando se ele cair; cada clique vira um evento processado de forma assíncrona e idempotente no MongoDB, e o cliente consulta estatísticas confiáveis de cada link.

Este plano entrega o critério 5 da ROADMAP: o `POST /links` acima do limite por IP responde 429 com `Retry-After`, contando o IP real quando a requisição vem de um proxy confiável e ignorando `X-Forwarded-For` de origem não confiável. Ele também é parte da mitigação parcial do T-08-06 (loop via DNS, Phase 1).

<objective>
Limitar a criação de links por IP com um script Lua de janela fixa no Valkey (D-08): INCR + PEXPIRE atômicos, só no `POST /links`, com 429 + `Retry-After` em Problem Details e fail-open se o Valkey cair. O IP real vem do `RemoteIpValve` do Tomcat (`server.forward-headers-strategy=native`), com `internal-proxies` explícito e vazio por padrão (RATE-02); o código nunca lê o header de proxy.

Purpose: protege a escrita contra criação em massa sem custo no redirect.
Output: `RateLimiter`, `RateLimitInterceptor`, `RateLimitProblems`, `WebMvcConfig`; `linkpulse.ratelimit.*`; config do `RemoteIpValve`; `RateLimitIT`, `TrustedProxyRateLimitIT`, `RateLimiterTest`; OpenAPI e README.
</objective>

Decisão travada implementada aqui: **D-08**. O rate limit é um script Lua de janela fixa (INCR + PEXPIRE), aplicado só no `POST /links` e fail-open se o Valkey cair. O IP real vem do `server.forward-headers-strategy=native` (`RemoteIpValve`), com `internal-proxies` restrito, e o código nunca lê o header de proxy (ARCHITECTURE.md Padrão 6, PITFALLS.md Armadilha 8).

Discricionariedade registrada (Claude's Discretion "Rate limit"):
- limite padrão de 20 requisições por minuto por IP, configurável por env;
- chave `lp:rl:{hmac do ip}:{índice da janela}`;
- `Retry-After` em segundos até o fim da janela;
- `internal-proxies` vazio no compose e CIDR do Traefik no kind (Phase 4), via `SERVER_TOMCAT_REMOTEIP_INTERNAL_PROXIES`.

Fatos da pesquisa que mudam o desenho:
- O default do Boot para `internal-proxies` confia em 10/8, 172.16/12, 192.168/16 e 127/8, o que inclui a rede bridge do Docker. Por isso o valor precisa ser explícito, e vazio desliga a confiança (verificado no bytecode do `RemoteIpValve` do Tomcat 11.0.24). Pitfall P5.
- O MockMvc não passa pelo `RemoteIpValve`. Por isso os ITs de RATE-02 usam `RANDOM_PORT` e um cliente HTTP real (Pitfall P8, "Desenho dos testes").
